One word for the boss: **Blamethrower** — a flamethrower that sprays blame instead of fire. The boss who, when anything goes wrong, hoses the whole team with fault.

## Run it

```sh
node main.ts
```

The program writes the word to `/output/entry.txt` (1–30 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
